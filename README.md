# laststory-native

A native PC port of The Last Story (Wii, USA `SLSEXJ`), built with static recompilation on
[Wiicompiled](https://github.com/patchzyy/Wiicompiled). No emulator at runtime.

Goals: 4K, locked 60 fps, a bloom toggle, preloaded shaders, Xbox controller layout with Xbox
button icons, and a SETUP launcher styled after the game's title screen.

> This repository holds no Nintendo or Mistwalker code, assets or game data, and never will.
> You need your own dump of the USA disc. Translation runs locally against your copy.

## Status

- `main.dol` translates: 21,421 functions, 78 unsupported instructions (all `mfspr` in
  debugger/exception code, to be stubbed).
- `LastWorld_tools.rso` is the developer debug menu and is not needed for retail play.
- Next: first native boot.

## Layout

| Path | What |
| --- | --- |
| `projects/laststory/recomp.yml` | Wiicompiled project file (memory layout, SDA bases r13 `0x808856C0`, r2 `0x808885A0`) |
| `projects/laststory/MAP.txt` | Function start addresses, generated by `tools/genmap.py` |
| `tools/genmap.py` | Builds the function map from call targets, data pointers and prologues |
| `tools/dol.py` | Tiny DOL disassembler for spot checks |
| `tools/translate.sh` | Builds the translator and translates your `main.dol` |
| `external/Wiicompiled` | Wiicompiled, pinned as a submodule |

## Translating

Needs the .NET 10 SDK (the 8.0.1xx SDK fails on an analyzer version), CMake, Ninja and Clang.

```sh
git submodule update --init
# unpack your disc first, e.g. nodtool extract game.wbfs extracted
tools/translate.sh extracted/sys/main.dol
```
